This project aims to find a way for a Raspberry Pi to process and analyze supplied images using a model trained using machine learning to accurately and efficiently predict what is within a given image. YOLOv5 is the name of this model, and it is one of the most popular and accurate image processing models that analyzes images in real time. We have successfully managed to allow an external camera, a SONY a6400, to communicate with the Raspberry Pi  and have its photos be processed and stored in an internal directory within the Pi. The code could easily be altered to allow for real-time live image processing, but the only limitation currently would be that the provided camera does not allow for images to be taken while it is plugged into the Pi.
